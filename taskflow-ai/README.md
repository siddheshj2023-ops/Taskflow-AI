# TaskFlow AI — SaaS Landing Page

A responsive front-end landing page for a fictional AI-powered project and productivity platform. Created as a front-end development internship assignment.

## Features
- Responsive desktop and mobile layouts
- Sticky navigation with working section links and mobile menu
- Hero section with CSS-built product dashboard preview
- Feature cards, how-it-works section, and two pricing plans
- Contact/demo form with name, email, and team-size validation
- Success and validation messages (front-end demo only)

## Technologies
- HTML5
- CSS3 (Grid, Flexbox, media queries)
- Vanilla JavaScript

## Run locally
1. Download and extract the ZIP.
2. Open the `taskflow-ai` folder.
3. Double-click `index.html`, or open the folder in VS Code and use the Live Server extension.
4. No backend, package installation, or API key is required.

## Design explanation (submission draft)
TaskFlow AI is a fictional SaaS productivity platform designed around a calm, modern visual style. I used a soft lavender palette, clear typography, and generous spacing to create a simple visual hierarchy. The landing page introduces the product through a dashboard preview, followed by feature cards, a three-step workflow, pricing plans, and a demo request form. CSS Grid and Flexbox are used to keep the layout responsive across desktop and mobile screens. JavaScript handles the mobile navigation, form validation, and success feedback. The main challenge was keeping the dashboard-style visual engaging while ensuring the page remained readable and usable on smaller screens.

## Notes
- This is a front-end-only demo. The form validates inputs and displays a local success message; it does not send or store submissions.
- Pricing and product details are illustrative sample content.
- Google Fonts are loaded online; system fallback fonts are provided.
